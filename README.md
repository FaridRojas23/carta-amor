# 💌 Carta de Amor - Te Amo Turromzita

Una página web interactiva y hermosa con una carta de amor inmersiva.

## ✨ Características

- 📱 Totalmente responsiva (funciona en iPhone, Android, computadora)
- 💕 Animaciones suaves y hermosas
- 🎉 Efecto de confeti al abrir la carta
- 🔐 Privada (solo tú y quien compartas el link)
- 🎨 Diseño moderno con gradientes

## 🚀 Cómo activar GitHub Pages

1. Ve a tu repositorio en GitHub
2. Ve a **Settings** → **Pages**
3. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Guarda los cambios
5. Espera unos minutos y tu página estará lista

## 📲 Cómo funciona

1. Al entrar al link, verás un sobre blanco con un corazón
2. Haz click en el sobre
3. Se abrirá una carta hermosa con el mensaje "Te amo turromzita"
4. Hay confeti cayendo para hacer más especial el momento
5. Puedes cerrar la carta y abrirla de nuevo

## 💡 Personalización

Si quieres cambiar el mensaje, edita el archivo `index.html` y modifica el texto.
